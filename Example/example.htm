Produk

Cahaya, bukan sekadar transparansi.

Setiap permukaan Verdant punya lapisan dasar, tint, specular highlight, dan definisi tepi. Hasilnya bukan blur di mana-mana, tapi material yang terasa punya ketebalan.

  • Hierarki material berlapis — konten utama selalu lebih tegas daripada dekorasi.
  • Fallback tanpa blur — layout tetap utuh di perangkat atau browser lama.
  • State yang dapat diprediksi — hover, fokus, ditekan, dan terpilih punya respons tetap.
  • Hormati preferensi gerak — parallax dan animasi non-esensial dimatikan otomatis.

FAQ

Pertanyaan yang sering muncul.

Belum menemukan jawabannya? Tim kami biasanya membalas dalam satu hari kerja.

Tanya tim Verdant
Apakah Liquid Glass di sini memakai API Apple?
Tidak. Liquid Glass di Verdant adalah arahan visual dan perilaku untuk web: transluensi kontekstual, blur terbatas, tint, specular highlight, dan definisi tepi. Semuanya dibangun dengan CSS standar dan tidak memakai API platform proprietary.
Bagaimana kalau browser tidak mendukung backdrop-filter?
Setiap permukaan punya fallback solid dengan opasitas tinggi. Hierarki visual tetap terbaca karena ditopang layout, tipografi, dan kontras — bukan hanya efek blur.
Apakah parallax mengganggu pengguna dengan sensitivitas gerak?
Tidak. Parallax hanya aktif pada layar lebar dengan pointer presisi, dan otomatis dimatikan saat prefers-reduced-motion bernilai reduce. Semua konten tetap tampil tanpa gerakan.
Bisakah saya membawa token yang sudah ada?
Bisa. Impor dari CSS variables, JSON, atau Figma Variables. Verdant memetakan token lama ke skala material kami, lalu menandai konflik kontras sebelum dipublikasikan.
Apakah ada batas jumlah komponen di paket gratis?
Paket Jelajah menyertakan 24 komponen inti dan satu proyek aktif. Tanpa batas waktu, tanpa kartu kredit. Anda bisa meningkatkan paket kapan saja tanpa kehilangan riwayat versi.
